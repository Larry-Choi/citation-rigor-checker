# 기본 프롬프트보다 낮았던 점수의 원인

이전의 **서지 macro-F1 0.781 대 0.670**만으로 스킬의 판단력이 더 낮다고 결론 내릴 수 없다. 두 조건의 정답 개수는 세 번 모두 동일한 **13·14·13/19개**였다. 서로 다른 유형의 오답에 가중치를 주는 macro-F1과 잘못 설계된 희소 클래스 하나가 순위를 바꿨다. 원본 라벨·예측·점수는 [v1 결과](comparison/summary.json)에 그대로 보존했다.

## 1. 실제 입력 오류와 판정 실패

- **R009:** 실제 GPflow 참고문헌의 `Variatinoally` 오타. 두 조건 모두 3/3회 발견했다.
- **R013:** 제공된 출판 레코드와 1년 다른 연도. 두 조건 모두 3/3회 review로 분류했다. 다른 버전의 연도까지 틀렸다고 단정한 결과는 아니다.
- **R015:** 제목에서 의미 있는 뒷부분이 누락됐다. 두 조건 모두 3/3회 review로 분류했다.
- **R016·R017:** 지정된 후보의 제목과 저자가 모두 다른 논문이다. 두 조건 모두 3/3회 identity conflict로 분류했다.
- **R018:** 제목은 같은데 저자가 Jane Smith로 바뀌었다. 두 조건 모두 저자 오류를 발견했다. 기본 프롬프트는 3/3회 identity conflict, 스킬은 3/3회 review로 보냈다. 오류 발견 능력 차이보다 **오류 등급 기준 차이**다. 보수적인 review 규칙은 원래 스킬에는 있고 기본 프롬프트에는 정의돼 있지 않았다. 새 비교에서는 같은 라벨 정의를 모두에게 제공한다.
- **의미 검증 15개:** 두 조건 모두 모든 반복에서 정답이었다. 기존 자료에서는 스킬이 근거 없는 주장을 승인한 사례가 관찰되지 않았다. 짧고 쉬운 자료의 천장 효과 때문에 추가 이득도 측정하지 못했다.

## 2. 정답이 유일하지 않거나 라벨이 잘못된 사례

- **R002 — 렌더링 경계:** 보호 중괄호·악센트·이중 이스케이프가 섞인 저자 이름이다. 이름 호환성을 인정하는 판정과 실제 출력 확인을 요청하는 판정이 모두 방어 가능하다. 새 주 평가에서는 제외하고, 보조 평가에서 matched/review를 둘 다 허용한다.
- **R012 — 인용 스타일 경계:** `GPflow`만 남기고 부제를 생략했다. 전체 제목을 요구하면 review, 짧은 제목을 허용하면 match가 가능하다. 주 평가에서 제외하고 두 판정을 허용하는 보조 점수도 남긴다. v1에서는 양쪽 모두 review였다.
- **R003·R004 — 라벨 결함:** `arXiv`와 `arXiv preprint arXiv:…`는 같은 식별자를 가리킨다. 차이가 있다는 이유만으로 review를 정답으로 둔 것은 과도했다. 두 조건의 정상적인 match 판정을 함께 감점했다.
- **R007·R014 — 정책 경계:** 정식 행사명과 축약·관용 이름의 차이다. 원래 평가는 review를 요구했지만 스킬은 이미 인정되는 약칭과 사실 오류를 구분하라고 지시했다. 새 루브릭에서는 뜻이 확실한 약칭을 match로 정했다. 연도·트랙·별도 권호가 충돌하는 경우까지 승인하는 규칙은 아니다.

이 재판정은 **동일 세션에서 수행한 사후 분석**이다. 독립 심사자가 확정한 정답으로 포장하지 않는다. [라벨 변경 내역](adjudicated-v2/adjudication.json)에 이전 값·이유·모호한 항목을 기록했다.

## 3. R019: 자료가 있는데 자료 없음으로 채점

R019의 `candidate_record_id`는 null이지만, 입력 전체의 `records`에 같은 제목·저자·연도의 `hensman2013gaussian`이 들어 있다. v1 정답은 unresolved였다.

- 기존 스킬 1·3회차는 그 레코드를 찾아 match로 판정했다. 실제 이유에도 자료를 찾았다고 명시했다. 그런데 채점은 오답 처리했다.
- 기존 스킬 2회차와 기본 프롬프트 3회차 모두는 지정 링크가 없다는 이유로 unresolved였다. 비교 범위가 명확하지 않았으므로 이 결과를 단순한 사실 오판으로 분류할 수도 없다.
- unresolved의 정답 사례는 이것 하나뿐이었다. 스킬의 해당 클래스 F1 평균은 0.333, 기본 프롬프트는 1.000이어서 전체 macro-F1에 크게 작용했다.

**R019만 양쪽에서 제외해도**, 원래 다른 라벨은 그대로 둔 채 macro-F1이 기본 **0.7079**, 스킬 **0.7908**로 역전된다. 이는 민감도 분석이며 새로운 성능 증거가 아니다. 계산 과정과 각 실행의 실제 이유는 [진단 JSON](diagnosis-v1.json)에 있다. 라벨을 바꾼 사후 재채점의 순위를 성능 향상으로 주장하지 않는다. 특히 정답에 없는 클래스까지 예측한 경우 macro-F1의 클래스 집합이 달라질 수 있어, 사후 재채점의 정답 개수와 개별 사례를 우선 확인해야 한다.

새 자료에서는 R019를 **자료는 있고 연결만 빠진 사례**로 유지한다. 별도의 **R020**을 추가해 실제로 관련 레코드가 전혀 없는 상황을 측정한다. R020은 합성 제어 항목이며, 실재하지 않는 논문을 발견했다는 예제가 아니다.

## 4. 원인에 맞춘 수정

1. **평가 기준:** 상태 이름만 열거하던 공통 프롬프트에 중립적인 라벨 정의와 후보 비교 범위를 명시했다. 기본 프롬프트도 보수적 저자 오류 분류 규칙을 받는다. 이제 이 규칙 자체를 스킬만의 성능 이득으로 셀 수 없다.
2. **스킬의 충돌:** “인정되는 약칭은 정상화”와 “약칭은 무조건 review”가 충돌하던 문장을 수정했다. 같은 뜻임이 확인된 표현은 허용하고, 불확실한 음역·제목 누락·설명되지 않은 연도 차이는 review로 보낸다.
3. **자료 재사용:** 연결 누락과 자료 부재를 분리했다. 제공된 자료만 검사하는 과제에서는 외부 검색·전문 열람을 했다고 주장하지 않는다. 지정된 후보가 있는 경우에는 그 후보와의 충돌을 다른 레코드로 덮어쓰지 않는다.
4. **모호한 라벨:** 실행 전에 R002·R012를 주 평가에서 제외하기로 고정했다. 전체 엄격 라벨 점수와 복수 정답을 허용한 보조 점수도 함께 공개한다.
5. **변경 효과 분리:** 기본 프롬프트·기존 스킬·수정 스킬을 같은 새 입력/루브릭으로 각각 3회 실행한다. 기존 스킬은 원본 해시가 일치하는 별도 파일로 고정했다. 평가 기준 수정과 새 스킬 문구의 효과를 혼동하지 않기 위해서다.

전체 스킬을 길게 재작성하거나 새 근거 없이 의미 검증 규칙을 추가하지 않았다. 기존 실행에서 확인된 실질적 단점은 더 긴 입력과 비용이다. v1 평균 입력은 기본 19,103토큰, 스킬 23,265토큰, 실행 시간은 23.08초와 27.25초였다. 문서 길이가 오판을 유발했다는 인과 증거는 없다.

## 5. 재비교의 해석

**9회 실행 결과는 모두 동점이었다.** 기본 프롬프트·기존 스킬·수정 스킬 각각 3회에서 서지 주 평가 18/18, 의미 15/15, macro-F1 1.000이었다. 모호한 두 항목을 포함한 전체 20개 엄격 라벨 평가와 복수 정답 허용 평가에서도 세 조건 모두 1.000이었다. 모든 실행이 35개 예측을 반환했고 도구 사용·실행 오류는 없었다.

기본 프롬프트도 명확한 공통 정의를 받으면 이 자료를 모두 해결했다. 기존 스킬과 수정 스킬도 같았으므로 **추가 문구 수정의 정확도 이득은 관찰되지 않았다**. 이전 열세는 평가 기준과 제어 사례에 크게 좌우됐고, 이를 고친 현재 자료에서는 우열을 측정할 수 없다. “수정해서 성능이 향상됐다”는 결론은 지지되지 않는다.

평균 입력 토큰은 기본 **19,005**, 기존 스킬 **23,607**, 수정 스킬 **23,802**였다. 수정 스킬은 기본 대비 약 **25.2%** 더 길다. 평균 실행 시간은 **22.25초 / 24.06초 / 24.57초**였으며, 이는 세 실행에서 관찰한 시간으로 일반적인 속도 차이를 보장하지 않는다. 이 짧은 자료에서는 추가 비용에 대응하는 정확도 이득이 없었다.

새 비교는 기존 오답을 본 뒤 고친 **개발 자료 재실험**이다. 독립 검증·전체 논문 검색 성능·국문 논문 성능을 나타내지 않는다. 의미 자료는 회귀 확인을 위해 그대로 뒀으며, 천장 효과는 해결되지 않았다. 같은 자료에서 수정 스킬이 이기더라도 일반적인 우월성으로 확대하지 않는다.
